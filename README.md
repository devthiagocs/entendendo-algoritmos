📚 Entendendo Algoritmos — Java

Repositório criado para armazenar minhas implementações e exercícios baseados no livro Entendendo Algoritmos, de Aditya Bhargava.

O objetivo é acompanhar meus estudos de Algoritmos e Estruturas de Dados, implementando os conceitos apresentados no livro utilizando Java.

🎯 Objetivos

* Aprender e reforçar conceitos fundamentais de algoritmos;
* Desenvolver raciocínio lógico e capacidade de resolução de problemas;
* Praticar a implementação de algoritmos em Java;
* Compreender a complexidade e o funcionamento dos algoritmos;
* Criar uma base sólida para estudos futuros de Estruturas de Dados e desenvolvimento de software.

📖 Conteúdos

Durante os estudos, o repositório aborda conceitos como:

* 🔎 Pesquisa Binária
* 🔄 Ordenação por Seleção
* 🔁 Recursão
* 📦 Pilha de Chamadas
* 🗺️ Tabelas Hash
* 🌐 Algoritmos de Busca em Largura (BFS)
* 🌳 Algoritmos em Grafos
* ⚡ Algoritmo de Dijkstra
* 🧩 Algoritmos de Divisão e Conquista
* 📊 Notação Big O
* 🤖 Algoritmos de Aprendizado de Máquina

Os conteúdos serão adicionados conforme avanço nos capítulos e exercícios do livro.

💡 Sobre o projeto

Este projeto faz parte da minha jornada de aprendizado em Ciência da Computação, com foco no desenvolvimento de uma base sólida em programação, algoritmos e resolução de problemas.

As implementações são feitas em Java, buscando não apenas reproduzir os exemplos do livro, mas também entender o funcionamento de cada algoritmo e praticar sua implementação.
